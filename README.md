# Library Management and Book Issuance System

A desktop library management system built with **C# .NET** and **SQLite** to streamline book circulation, track borrowing records, and manage student registrations for the **Philippine Technological Institute of Science, Arts, and Trade-Central Inc.**

---

## 📌 Overview

This application automates daily library operations, providing a lightweight and reliable way to track book movements and maintain accurate student borrowing records. By linking student profiles directly to book issuance logs using a local SQLite database, the system ensures fast performance, transparency, and simple administrative management.

---

## ✨ Features

* **Student Registration & Management:** Register and maintain student profiles to track active borrowers.
* **Book Issuance & Return Tracking:** Monitor checked-out books, record due dates, and manage return statuses.
* **Library Inventory Operations:** Catalog library books and track item availability in real time.
* **Borrowing History Logs:** View historical borrowing records and student issuance history.
* **Lightweight Embedded Storage:** Uses a local SQLite database file—no external server setup required.

---

## 🛠️ Built With

* **Language:** C#
* **Framework:** .NET Framework / .NET Desktop (Windows Forms / WPF)
* **Database:** SQLite (`System.Data.SQLite` / `Microsoft.Data.SQLite`)
